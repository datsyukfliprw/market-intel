# On-Call Handbook

## Responsibilities

-   Respond to alerts
-   Classify incidents
-   Coordinate responders
-   Communicate status
-   Escalate when needed

## Golden Rules

1.  Protect customers first.
2.  Stabilize before optimizing.
3.  Communicate frequently.
4.  Document everything.

## Escalation

Primary → Secondary → Engineering Manager → Executive

## Shift Handoff

-   Active incidents
-   Pending maintenance
-   Risks
-   Follow-up actions

## Burnout Prevention

-   Rotate schedules
-   Mandatory recovery time
-   Review alert fatigue
