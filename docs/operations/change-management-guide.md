# Change Management Guide

## Objectives

Reduce production risk while maintaining delivery speed.

## Change Types

-   Standard
-   Normal
-   Emergency

## Approval Matrix

  Type        Approval
  ----------- ----------------------
  Standard    Pre-approved
  Normal      Tech Lead + Reviewer
  Emergency   Incident Commander

## Deployment Checklist

-   Tests passing
-   Rollback validated
-   Monitoring ready
-   Release notes complete
-   Stakeholders notified

## Post-Change Review

-   Success criteria met
-   Metrics stable
-   Lessons recorded
