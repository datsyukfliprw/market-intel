# Production Operations Manual

## Objectives

Maintain reliable, observable, secure production services.

## Daily Operations

-   Review alerts
-   Review failed jobs
-   Review backups
-   Capacity dashboard
-   Security events

## Deployment Standards

-   Automated tests required
-   Rollback documented
-   Feature flags preferred
-   Database migrations reversible

## Operational Metrics

-   Availability
-   Latency
-   Error rate
-   Queue depth
-   Scan throughput

## Backup Policy

-   Daily database backup
-   Weekly restore verification
-   Quarterly disaster exercise

## Maintenance Window Checklist

-   Stakeholder notification
-   Snapshot
-   Deploy
-   Smoke tests
-   Monitoring validation
-   Close window
